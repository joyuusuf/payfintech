PayFintech

PayFintech is a simple frontend fintech web app built with HTML, CSS, and JavaScript. 
It simulates core financial services such as sending and receiving money, viewing account balance, and managing basic transactions—all through a clean and responsive interface.

 Features

- User-friendly and responsive design
- Simulated wallet/account dashboard
- Send and receive money functionality (UI only)
- Transaction history display
- Interactive UI elements built with vanilla JavaScript

 Technologies Used

- HTML – For semantic markup and structure
- CSS3 – For styling and layout (includes responsive design)
- JavaScript – For UI interactivity and dynamic updates
